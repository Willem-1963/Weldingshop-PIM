# GUI v3

Professionele modulaire GUI-basis voor Weldingshop Product Platform.

## Belangrijkste verbeteringen

- Modulaire GUI-bestanden.
- Donkere navigatiebalk.
- KPI-kaarten bovenin.
- Producttabel met prijsnotatie en statuskolommen.
- Productdetail met tabs.
- Echte afbeeldingsweergave via QPixmap.
- Thumbnails in tabblad Afbeeldingen.
- Correcte euro- en UTF-8-tekens.

## Starten

```powershell
py -m app.gui.app
```
